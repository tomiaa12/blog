# 英语习题

以下为连载练习，每期 20 题。建议在输入框自写英文，再点「检查」对照参考答案；参考答案默认遮挡，桌面端可悬停查看，也可点击色块切换显示。

**说明：** 原稿连载在「第6期」与「第8期」之间未编第 7 期，故本站目录亦无 `issue-07`。另「第14期」与「第17期」之间未标第 16 期，故亦无 `issue-16`；夹在中间的**非谓语作状语**按顺序编为**第15期**。第 21–22、23–24、25–26、29–31、32–34、35–36、37–38、41–42、43–45、46–47、48–50 期为原稿合刊，本站以连字符文件名对应（如 `issue-32-34`）；第 39、40 期为单期。
